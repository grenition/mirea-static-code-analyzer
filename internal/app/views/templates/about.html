About

Technology Stack
  • Frontend: HTML5, CSS3, JavaScript, Bootstrap 5
  • Backend: Golang
  • Database: PostgreSQL
  • Architecture: MVC (Model-View-Controller)
Analysis Rules

The analyzer checks code against the following rules:

  • LINE_TOO_LONG (warn) - Lines exceeding 120 characters
  • TRAILING_WHITESPACE (info) - Trailing spaces or tabs
  • TAB_INDENT (info) - Tab characters in code
  • TODO_FOUND (warn) - TODO or FIXME comments
  • DEBUG_PRINT (info) - Debug print statements
  • HARDCODED_SECRET (error) - Potential hardcoded secrets
  • INSECURE_HTTP_URL (warn) - Insecure HTTP URLs
  • FILE_TOO_LARGE (warn) - Files exceeding 800 lines
Limitations
  • This is a primitive analyzer that works on plain text, not AST
  • ZIP uploads are limited to 20 MB
  • Code snippets are limited to 50,000 characters
  • Only specific file extensions are analyzed (see allowed extensions)
  • Analysis is synchronous (no background processing)
  • No semantic analysis - only pattern matching
Supported File Extensions

.go, .cs, .js, .ts, .py, .java, .cpp, .h, .hpp, .php, .rb, .kt, .swift, .sql, .html, .css, .md
