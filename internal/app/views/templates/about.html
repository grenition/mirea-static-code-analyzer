О проекте

Технологический стек
  • Frontend: HTML5, CSS3, JavaScript, Bootstrap 5, Bootstrap Icons
  • Backend: Golang
  • База данных: PostgreSQL
  • Архитектура: MVC (Model-View-Controller)
  • Хранение данных: PostgreSQL (файлы и результаты анализа)
  • Деплой: Docker, Docker compose
Правила анализа

Анализатор проверяет код по следующим правилам:

  • LINE_TOO_LONG (предупреждение) - Строки, превышающие 120 символов
  • TRAILING_WHITESPACE (информация) - Завершающие пробелы или табы
  • TAB_INDENT (информация) - Табуляция в коде
  • TODO_FOUND (предупреждение) - Комментарии TODO или FIXME
  • DEBUG_PRINT (информация) - Отладочные операторы вывода
  • HARDCODED_SECRET (ошибка) - Потенциально захардкоженные секреты
  • INSECURE_HTTP_URL (предупреждение) - Небезопасные HTTP URL
  • FILE_TOO_LARGE (предупреждение) - Файлы, превышающие 800 строк
Ограничения
  • ZIP-загрузки ограничены 20 МБ
  • Фрагменты кода ограничены 50,000 символов
  • Анализируются только определённые расширения файлов
  • Анализ синхронный (без фоновой обработки)
  • Для работы линтеров требуется запущенный Docker-контейнер
Поддерживаемые языки и линтеры
  • JavaScript/TypeScript: ESLint
  • Python: Pylint
  • Go: golangci-lint
  • C/C++: cppcheck
  • PHP: PHP Syntax Checker

Также поддерживаются паттерн-правила для всех языков: .go, .cs, .js, .ts, .py, .cpp, .h, .hpp, .php, .kt, .swift, .sql, .html, .css, .md
