# Введение

В современной разработке программного обеспечения часто возникают ситуации, когда необходимо быстро проверить код на наличие ошибок, но при этом нет возможности или времени устанавливать полноценную интегрированную среду разработки (IDE). Например, при работе на новом устройстве или при быстрой проверке чужого кода. Установка IDE и настройка плагинов для статического анализа может занять значительное время и требует определённых системных ресурсов.

В таких случаях разработчикам нужен быстрый и доступный способ проверки кода без необходимости установки дополнительного программного обеспечения. Это приводит к повышенному спросу на веб-инструменты, способные анализировать исходный код прямо в браузере и предоставлять информацию о найденных проблемах в удобном виде.

Одним из таких инструментов являются веб-приложения для статического анализа кода — сервисы, которые проверяют исходный код на наличие ошибок, предупреждений и потенциальных проблем без его выполнения и без необходимости установки программ на локальную машину. Они существенно экономят время разработчиков, предоставляя возможность проверять код по различным правилам, фильтровать результаты по уровню серьёзности и получать детальную информацию о каждой найденной проблеме.

Актуальность разработки веб-приложения для статического анализа кода обусловлена необходимостью предоставления разработчикам быстрого и доступного способа проверки кода в ситуациях, когда установка IDE затруднена или невозможна.

Целью данной работы является проектирование и разработка серверной части веб-приложения «Анализатор статического кода».

Для достижения указанной цели требуется решить следующие основные задачи:
-	провести анализ предметной области разрабатываемого веб-приложения,
-	определить потребности пользователей веб-приложения,
-	разработать клиентскую часть веб-приложения с использованием технологий HTML5, CSS3 и JavaScript,
-	реализовать серверную часть и логику взаимодействия с базой данных,
-	протестировать работу веб-приложения.

Объектом исследования является веб-приложение, предназначенное для статического анализа исходного кода.

Предметом исследования является процесс разработки данного веб-приложения.

Информационной базой исследования являются интернет-источники, методические материалы и аналогичные веб-приложения по схожей тематике. 

Методы исследования включают изучение аналогичных веб-приложений и применение полученных знаний на практике.
