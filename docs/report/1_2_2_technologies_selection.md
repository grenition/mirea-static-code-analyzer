### Выбор технологий разработки

При проектировании веб-приложения «Анализатор статического кода» необходимо было подобрать набор технологий, который обеспечит надёжную работу системы и простую интеграцию инструментов анализа кода. В процессе выбора изучались готовые сервисы для статического анализа и современные веб-фреймворки, но они оказались либо слишком ограниченными, либо излишне сложными для данного проекта, в результате чего выбор пал на стандартные веб-технологии и серверные решения.

Клиентская часть построена на базе HTML5, CSS3 и JavaScript с использованием фреймворка Bootstrap 5. HTML5 обеспечивает структурированную разметку страниц, CSS3 — современный дизайн для удобного отображения результатов анализа, JavaScript — интерактивность и динамическое обновление данных. Bootstrap 5 используется для быстрой разработки интерфейса и обеспечения адаптивности.

Серверная часть реализована на языке программирования Go. Этот язык обеспечивает высокую производительность, удобную работу с конкурентностью и эффективную организацию MVC-архитектуры [14], обработку маршрутов, работу с файлами и выполнение CRUD-операций [15]. Go хорошо интегрируется с Docker и позволяет легко запускать внешние программы для выполнения линтеров.

В качестве системы управления базами данных выбрана PostgreSQL. Данная СУБД [16] обеспечивает быстрые запросы, поддержку хранения бинарных данных для содержимого анализируемых файлов и удобную работу с реляционными структурами. PostgreSQL интегрируется с Go через драйвер lib/pq [17], что гарантирует безопасное выполнение запросов.

Для развёртывания приложения использована контейнеризация через Docker и Docker Compose. Это решение позволяет запускать веб-приложение, базу данных PostgreSQL и набор линтеров в изолированных контейнерах, обеспечивая одинаковое поведение на любой системе. Выделение линтеров в отдельный контейнер обеспечивает платформенную независимость и упрощает добавление новых инструментов анализа.

Для статического анализа кода применяются линтеры: ESLint для JavaScript и TypeScript, Pylint для Python, golangci-lint для Go, cppcheck для C/C++ и встроенный синтаксический анализатор PHP. Эти инструменты широко используются в промышленной разработке и способны выявлять различные типы проблем в коде.
