# Основная часть

## Общие сведения

### Функциональное назначение

Веб-сервис статического анализа программного кода предназначен для проверки исходного кода на наличие ошибок, предупреждений и потенциальных проблем без необходимости установки дополнительного программного обеспечения на локальную машину. Сервис формирует единое пространство, где разработчики могут оперативно проверять свой код на различных языках программирования через обычный веб-браузер.

Для реализации данной задачи приложение включает ключевые функции: загрузку ZIP-архивов с проектами для полного анализа всех файлов, интерактивный анализ фрагментов кода в реальном времени с возможностью выбора языка программирования, просмотр истории всех выполненных анализов с детальной информацией о найденных проблемах, а также просмотр содержимого проанализированных файлов.

Для обеспечения конфиденциальности данных и разделения анализов между пользователями реализована система авторизации, которая позволяет пользователям регистрироваться, входить в систему и иметь доступ только к своей истории анализов, включая возможность удаления ненужных записей.

### Прикладное программное обеспечение

При создании веб-сервиса статического анализа программного кода применялся набор современных инструментов и технологий, которые обеспечивают эффективную разработку, тестирование и запуск приложения.

Основным инструментом для написания кода служил редактор Visual Studio Code [1] с набором расширений, поддерживающих работу с языком программирования Go [2], разметкой HTML5 [3], стилями CSS3 [4], скриптами JavaScript [5] и контейнеризацией Docker [6].

Локальное развертывание всех компонентов системы организовано с помощью Docker Compose, который управляет контейнерами с веб-приложением на Go, базой данных PostgreSQL [7] и отдельным контейнером, содержащим набор линтеров для различных языков программирования.

Анализ кода выполняется с использованием специализированных инструментов: ESLint [8] для проверки JavaScript и TypeScript, Pylint [9] для анализа Python-кода, golangci-lint [10] для Go, cppcheck [11] для проверки C/C++, а также встроенного синтаксического анализатора PHP.

Проверка работоспособности и корректности отображения веб-интерфейса осуществлялась в браузере Google Chrome.
