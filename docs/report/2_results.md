## Заключение

В ходе выполнения курсовой работы проведен анализ предметной области, оценка популярных сервисов статического анализа кода. Выявлены необходимые пользователям функции и возможности. Определены цели и задачи для разработки веб-приложения, а также выбраны современные технологии разработки.

На этапе проектирования разработана архитектура веб-приложения на основе паттерна MVC, что позволило чётко разделить клиентскую часть, серверную логику и слой работы с базой данных.

Создан и реализован слой серверной логики, обеспечивающий обработку запросов, маршрутизацию, выполнение бизнес-операций, взаимодействие с хранилищем данных и интеграцию с Docker-контейнерами для запуска линтеров различных языков программирования.

Разработан слой логики базы данных. Спроектирована структура таблиц, реализовано подключение и работа с PostgreSQL, созданы модели и репозитории, обеспечивающие выполнение CRUD-операций с пользователями, проектами, анализами, найденными проблемами и файлами.

Создан слой клиентского представления веб-приложения, включающий интерфейс для пользователей с поддержкой авторизации. Использованы HTML5, CSS3 и JavaScript, обеспечивающие корректное отображение результатов анализа, динамическое взаимодействие с элементами страницы, фильтрацию проблем и просмотр содержимого файлов.

В результате было разработано веб-приложение «Анализатор статического кода», удовлетворяющее требованиям пользователей и обеспечивающее удобный доступ к инструментам статического анализа кода без необходимости установки дополнительного программного обеспечения.

Для демонстрации проделанной работы создана презентация.

Все поставленные цели и задачи выполнены.
