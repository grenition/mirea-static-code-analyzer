## Проектирование и разработка веб-приложения

### Анализ предметной области разрабатываемого веб-приложения

Для анализа предметной области были изучены сервисы-аналоги, связанные с тематикой курсовой работы. В качестве аналогичных ресурсов рассмотрены следующие веб-приложения: SonarQube [12] (рисунок 2.1), ESLint Playground [13] (рисунок 2.2).

SonarQube – одна из самых популярных платформ для статического анализа кода, предоставляющая комплексную проверку качества кода для множества языков программирования. Сервис позволяет анализировать большие проекты, отслеживать технический долг, находить уязвимости безопасности и проверять соответствие стандартам кодирования. Однако при всей своей функциональности SonarQube требует установки и настройки сервера, что делает его неудобным для быстрой проверки кода без предварительной подготовки. Кроме того, интерфейс платформы достаточно сложный и перегруженный различными метриками и графиками, что может затруднить быстрый поиск конкретных проблем в коде.
 
Рисунок 2.1 – Сервис статического анализа кода SonarQube

ESLint Playground – онлайн-инструмент для проверки JavaScript и TypeScript кода с использованием линтера ESLint. Сервис предоставляет простой и понятный интерфейс для быстрой проверки фрагментов кода прямо в браузере. Однако платформа ограничена только языками JavaScript и TypeScript, что не позволяет использовать её для анализа кода на других языках программирования. Кроме того, сервис не сохраняет историю анализов и не предоставляет возможности загрузки целых проектов в виде архивов.

В ходе анализа предметной области разрабатываемого веб-приложения была произведена оценка целевой аудитории сайта – это разработчики, которые хотят быстро проверить код на наличие ошибок без необходимости установки IDE или настройки сложных инструментов. Благодаря этому выполнены ключевые запросы пользователей:
-	возможность проверки кода прямо в браузере без установки дополнительного ПО,
-	поддержка нескольких языков программирования,
-	простая и понятная подача результатов анализа,
-	возможность работы с отдельными файлами и целыми проектами.

Изучив и сравнив несколько решений, выделим общие критерии:
-	наличие веб-интерфейса для загрузки и анализа кода,
-	поддержка популярных языков программирования,
-	отображение найденных проблем с указанием файла, строки и описания ошибки.
